# 01 — Single Sign-On (SSO)

## Scope

Study and demonstrate how enterprise applications use federated identity and access management.

## Topics

- Authentication vs authorization
- SAML 2.0
- OAuth 2.0
- OpenID Connect (OIDC)
- JWT
- SCIM
- MFA and session management
- Role / group mapping

## Practical goal

Document: **User → Application → Identity Provider → Token / Assertion → Application session**.

## Questions

1. Where does authentication happen?
2. What is the difference between SAML and OIDC?
3. Why is OAuth not itself an authentication protocol?
4. What information does an ID token contain?
5. How does SCIM complement SSO?
6. What happens when an employee leaves an organization?
