# 03 — iPaaS

## Scope

Understand Integration Platform as a Service as an enterprise layer for connecting applications, APIs, data and business processes.

## Core concepts

- Connectors
- APIs
- Webhooks / events
- Authentication
- Data mapping
- Transformations
- Workflow orchestration
- Error handling and retries
- Monitoring
- API management

## ETL vs iPaaS

**ETL is primarily data-centric:** move and transform data.

**iPaaS is primarily integration/process-centric:** connect applications and orchestrate processes.

The distinction is not absolute; modern platforms can overlap.

## MuleSoft

Focus on Anypoint Platform, API-led connectivity, System APIs, Process APIs, Experience APIs, DataWeave and API management.

## Workato

Focus on recipes, triggers/actions, connectors, business-process automation, error handling and monitoring.

## Practical goal

Design an integration connecting at least three enterprise systems and explain the trigger, data flow, transformation, authentication, error handling and monitoring.
